# Symphony No. 9 - Android app

Capacitor project. The Android project folder (android/) is generated by the GitHub build,
so you don't need Android Studio to get an APK.

## Build on GitHub
Push this repo. The "Build Android APK" workflow runs on each push to main and uploads
app-debug.apk as an artifact. Download it from the run's Artifacts section and install it on your phone
(allow "Install unknown apps" for your browser or file manager).
